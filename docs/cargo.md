# 積荷の初期配置（Issue #15）

段ボールを荷台に1段で載せる。荷物ごとに状態・位置・速度を持ち、滑り（#16）・落下（#17）でこの値を更新する。

## 大きさ

イシューの初期値（荷台 2.0×3.0・荷物0.5）ではなく、今のトラックの模型（`createTruck`、車体1.2×2.4）に合わせた。トラックの見た目・当たり判定・走りの調整（#27）を変えないため。

| 値                           | 初期値            | 中身                                                   |
| ---------------------------- | ----------------- | ------------------------------------------------------ |
| 荷物数                       | 3                 | `CARGO.count`                                          |
| 荷物の大きさ                 | 0.4               | `CARGO.size`（立方体の一辺）                           |
| 荷物どうし・あおりとのすき間 | 0.08              | `CARGO.gap`                                            |
| 荷台の幅                     | 1.08              | `BED.width`（左右のあおりの内側）                      |
| 荷台の長さ                   | 1.39              | `BED.length`（後ろのあおりから運転席の背面まで）       |
| 荷台の中心                   | (0, 0.55, −0.395) | `BED.center`（トラックのローカル座標。高さは荷台の床） |

荷物は荷台の幅の約1/3で、イシューの比率（0.5÷2.0）に近い。

## 並べ方（`createCargoLayout`）

- 幅方向に入るだけ（今の荷台では2個）並べ、前（運転席側）の列から埋める。列は荷台の前後に均等に広げ、各列は左右の中央にそろえる。
- 1個なら荷台の真ん中、3個なら前に2個・後ろに1個（中央）。
- 1段で載らない数・大きさはエラーにする（今の荷台では4個まで）。

## 座標と状態

- 位置・速度は荷台の中心を原点にしたローカル座標 `{x, z}`（トラックと同じ向き：+z が前、+x が左）。`bedToTruck` でトラックのローカル座標に直す。
- 状態は `resting`（荷台で止まっている）・`sliding`（荷台の上を滑っている、#16）・`falling`（荷台から落ちている、#17）・`lost`（落ちて失った）。
- `remainingCargo` は荷台に残っている数（`resting` と `sliding`）。

## ゲームへの組み込み

- `createCargo` が段ボール（テープ付き）を作り、トラックの子として荷台に載せる。トラックと一緒に動く。
- 「STARTに戻す」・「もう一度」で積み直す。
- リザルトの積荷は「残っている数 / 積んだ数」で表示する（#17 までは落ちないので 3 / 3）。

確認：`npm run test:cargo`（初期値、1個・3個の並び、荷物ごとの状態、座標の変換、載らない数のエラー）。

## 滑り物理（Issue #16）

`slideCargo.ts` は1/60秒ごとに積荷を更新する。トラックも同じ刻みで更新し、速度の差から前後加速度、角度の差から旋回速度（yawRate）を取得する。

- 前後の慣性加速度は `-acceleration`。加速すると後ろ、ブレーキで前へ滑る。
- 横の慣性加速度は `-speed * yawRate`。左旋回で右、右旋回で左へ滑る。
- 静止摩擦係数0.25、動摩擦係数0.18、重力9.8。止まっている荷物は静止摩擦の限界を超えると滑り始める。滑っている荷物は動摩擦で減速する。
- 速度を先に、位置を後から更新する半陰的オイラー法。摩擦で速度が逆転しないようにする。
- 一時停止中は更新せず、リセットで位置・速度・更新待ち時間を初期化する。
- 現段階では荷台の端で止める。落下（#17）は含めない。荷物どうしが接触したら重なりを押し戻し、接触方向の速度をそろえる。荷台の端で押し戻せない分は相手側を動かす。密集して解消できない場合は直前の配置で止める。

確認：`node --test tests/cargo-sliding.test.ts`。方向、摩擦の境界、停止、更新式、荷台端を確認する。
