# 写真の色でつける坂

写真の壁の色（人物の色）の明るさで、コースに上り坂・下り坂をつける。明るいところほど高く、暗いところほど低い。高さは `CourseData` から毎回計算し、データベースには保存しない。保存済みのコースにも、同じ坂がつく。

## 高さの決め方

`src/game/elevation.ts` の `createElevation` が、中心線に沿って1mごとに次の順で計算する。

1. 壁の色を `createRoad` と同じ補間で取り、明るさ（CIE L\*）にする
2. コースの中で一番暗いところを0、一番明るいところを1にそろえ、`maxHeight`（10m）をかける
3. STARTの前後30mと、お家の前後20mは高さ0の平らな場所にする。配送センターとお家は地面に置いたままにする
4. 坂の急さを7%以下に抑える。前後から何周かたどり、隣より高すぎるところだけを削る
5. 幅 2×7%×450m（63m）の移動平均でならし、坂の頂上・底の丸みを半径450m以上にする

坂の急さ7%と丸み450mは、道路構造令の設計速度40km/hの値（縦断勾配・縦断曲線半径）。ふつうに走る速さ（40〜50km/h）の道と同じくらいの坂になる。手順5の移動平均は、坂の急さが7%以下の形をならすので、ならしたあとも7%を超えない。手順3の平らな場所は、ならしても崩れないよう、ならす幅の半分だけ広く0にしてからならす。

色が1色だけのコースや、短いサンプルコース（一周約130m）は、平らな場所とならす幅でほぼ全部が埋まり、平らな道のままになる。

## 見た目

`createRoad` に各点の高さを渡すと、道路と壁をその高さに置く。外側の壁は地面まで下ろし、高いところでは道を支える土手に見せる。トラックは道路の高さに置き、坂に合わせて前後に傾ける。カメラも道路の高さに合わせて追いかける。

## 走り・荷物

`updateGame` に、トラックの向きでの坂の急さ（上りが正）を渡す。重力の坂に沿った分（9.8×急さ）だけ、上り坂で減速し、下り坂で加速する。坂の角度は小さいので、正弦は急さで近似する。

`slideCargo` にも同じ急さを渡す。上り坂では荷物が後ろへ、下り坂では前へ引かれる。発進の補助（`cargoLaunchScale`）は加速の分だけにかけ、坂の重力にはかけない。今の摩擦（静止0.25）では、7%の坂だけで止まっている荷物は滑らない。加速・ブレーキ・カーブの力と足し合わさって、平らな道より少し滑りやすくなる。

`updateCargoFalls` には、トラックのいる道路の高さと、落ちた場所の高さを返す関数を渡す。道の上に落ちた荷物は道路の高さに、道の外（土手の下）に落ちた荷物は地面に着く。

## 変えていないこと

荷物の摩擦、柵、ミニマップ、周回とゴールの判定（平面のまま）は変えていない。坂の頂上で荷物が浮く動きは作っていない。道路の基準どおりの丸み（450m）では、約238km/hを超えないと浮かないため。

`npm run test:slope`：明るさの計算、明るい色ほど高いこと、坂の急さ7%以下・丸み450m以上、STARTとお家のまわりが平らなこと、1色やサンプルコースが平らなこと、上り坂での減速・下り坂での加速、荷物が7%では滑らず急な坂では後ろへ滑ること、落ちた荷物が道路の高さに着くことを確認する。
