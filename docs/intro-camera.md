# コース紹介カメラ

ゲーム画面を開くと、斜め上の全体図を0.65秒見せ、その後3.2秒でトラック後方の追従カメラへ移る。位置と注視点の両方を滑らかに補間し、終点で通常の追従位置へつなぐ。時間は `introCamera.ts` の `INTRO_CAMERA` で調整できる。

演出中はキー入力と走行シミュレーションを進めず、タイムと積荷も動かさない。画面が隠れている間は演出時間も進めない。スキップ、カメラ切替、STARTへのリセットで演出を終了できる。通常のリセットでは演出を繰り返さない。端末の「動きを減らす」設定が有効なら最初から追従カメラにする。

描画・カメラ処理は既存のゲームループ内で行う。スマホ通信や道路データには変更を加えない。
