# 配送センターからの出発演出

約6秒で全体俯瞰から配送センターへ寄り、出庫するトラックを横から追って右折と同時に後方カメラへ移る。最初の2秒は車庫内で停止し、次の1秒で出庫、残り3秒で右折してSTART位置へ停止する。

車庫と配送会社の建物は進行方向の右側へ配置する。看板はBodriveのみとし、車庫はトラックに合わせた大きさにする。カメラは出庫中、運転席から見て斜め左前を追跡し、右折中は右ウインカーを点滅させる。合流口は白・赤のバー式ゲートで表示する。出庫中はバーを上げ、START到着後に約1秒で下ろす。通常走行の衝突境界は維持する。スタート・ゴールは市松模様から白い停止線へ変更し、トラック先端の少し前へ配置する。周回判定の基準座標は維持する。

演出中は走行・タイム・積荷の物理計算を進めない。非表示中は演出時間も止める。演出終了後、操作準備ができたら3・2・1・Go!へ移る。通常リセットでは出庫を繰り返さず、動きを減らす設定では演出を省略する。

`depotDeparture.ts`の`departurePose`で軌道を定義し、`tests/depot-departure.test.ts`で車庫内の待機、右折と終了位置、軌道の連続性を確認する。
