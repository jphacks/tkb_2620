# 写真画面の検証UI整理

写真画面から「人物の色を取り出す」「輪郭の検証・平滑化の調整」の検証パネルを外す。比較Canvas、サンプル、色見本、設定スライダーはプレイヤーに表示しない。

輪郭抽出、平滑化、等間隔化、急カーブ補正、カラー抽出・対応づけの処理は維持する。写真選択後に標準設定で実行する。カラー抽出は `photoColors.ts` に分離し、表示用Canvasに依存しない。

色の取得中は処理中の表示を出し、処理済みの写真と結果が一致する場合だけ「この写真を使う」を有効にする。写真を素早く選び直しても古い結果を反映しない。失敗時には再判定・別の写真の選択を案内する。

写真選択、黄色い輪郭プレビュー、START表示、選び直し、コース生成はそのまま。写真のサーバー送信や保存は追加しない。検証コンポーネントは他の開発で再利用できるようファイルを残すが、写真画面からは読み込まない。
