# エラー時の最低限処理（Issue #22）

エラーが起きてもアプリ全体が止まらないようにする。失敗したら理由を出して、やり直せる画面へ戻す。

## 写真・コースの失敗

| 場面                       | 動き                                                                                                     |
| -------------------------- | -------------------------------------------------------------------------------------------------------- |
| 人物を認識できない         | 写真画面のまま理由を表示し、「この写真を使う」を押せないようにする（別の写真を選ぶ／もう一度判定する）   |
| 輪郭の平滑化に失敗         | 例外で画面を止めず、写真画面に「輪郭を作れませんでした」と理由を表示する                                 |
| コースの生成に失敗         | 完成画面から写真画面へ戻し、上部に理由と「別の写真を選ぶか、ポーズを変えて撮り直してください」を表示する |
| 作ったコースのデータが不正 | 「このルートで遊ぶ」で検査し、不正なら写真画面へ戻す。ゲーム画面でも検査し、不正ならサンプルコースで走る |

## 想定外のエラー

`src/components/ErrorBoundary.tsx` で画面の中身を包み、描画中のエラーを受け止める。ヘッダーと画面の切り替えは残したまま「問題が起きたため、画面を止めました」と表示し、「写真からやり直す」「ホームへ戻る」で中身を作り直す。

## スマホの通信切断（ゲーム中）

ゲーム画面にいる間、参加したスマホの担当（ハンドル・アクセル/ブレーキ）を覚えておき、次のどれかで一時停止する（`controllerLossReason`）。

- その担当のスマホがルームから抜けた（ページを閉じた・通信が切れた）
- 担当はルームにいるが、操作が1.5秒届かない（画面ロック・電波が悪いなど）。参加直後でまだ一度も届いていない担当は対象外
- PC とサーバーの接続が切れた

一時停止の間はトラックを止め、タイムも進めない。中央に理由と、次のボタンを出す。

- スマホが戻れば自動で再開する（QR を読み直す）
- 「キーボードで続ける」：スマホを待たずに続ける（覚えていた担当を忘れる）
- 「STARTに戻す」：トラックをSTARTからやり直す
- 「ホームへ戻る」：ロビー（ホーム）へ

スマホを使わずキーボードだけで遊んでいるときは、一時停止しない。

## NaN・異常値

`src/game/safety.ts`

- `sanitizeDriveInput`：スマホからの操作値を、NaN・無限大は0、範囲外は丸めてからゲームに渡す（サーバーでも丸めている）。
- `updateGame`：計算後のトラックの状態に NaN・無限大があれば、位置を飛ばさずその場で止める。`createScene` は状態が壊れていたら START に戻す。
- `validateCourseData`：コースの点・道幅・壁の色・テーマ色・撮影モードを検査する。

確認：`npm run test:safety`（コースの検査、操作値の丸め、NaNでもトラックが飛ばない、切断の判定）。
