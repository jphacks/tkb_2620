# 構成の参考資料

作品の文章・画像を転載せず、説明の順序や伝え方を参考にしました。Bodriveの実装に関する記述は、このリポジトリのコードと開発中のやり取りを根拠にしています。

## 提供された資料

- ジャッジニア `judgineer-slides.pdf`（18枚）：短い背景説明、実画面、特長、技術、締めへ進む構成を確認しました。Bodriveでは背景を1枚に絞り、早めにデモを置きました。参考資料そのものは再配布していません。

## 過去の受賞者が公開した資料

- [OriCube開発者・河村悠太さんのTSKaigi2025 LT資料](https://speakerdeck.com/yutakawamura/tskaigi2025-ltdeng-tan-zi-liao)：製品紹介と技術説明を分ける構成、発表資料から抜粋された機能紹介を参照。これはJPHACKS本番スライド全体ではなく、後日の登壇資料です。[2024公式受賞結果](https://jphacks.com/2024/result/innovator/)でBest Hack AwardとBest Audience Awardを確認しました。
- [JPHACKS2021優勝者による発表の振り返り](https://terublog.hatenablog.com/entry/2021/12/24/032526)：当事者の動機、独自性、技術の理由、デモを一貫して伝える考え方を参考にしました。こちらはスライド本体ではなく解説記事です。
- [革靴メンテなんです!! 開発者の紹介・振り返り](https://note.com/haruto869217/n/n556f4fe14fee)：具体的な利用場面、実物のデモ、こだわりを中心に説明する方針を参照。[2023公式受賞結果](https://jphacks.com/2023/result/)でBest Hack Awardを確認しました。添付スライド本体は取得できなかったため、スライドを閲覧した扱いにはしていません。

- ハンドル・ペダル・人物コース・配達員登録・走行画面：2026年10月25日にユーザーから提供されたBodriveのスクリーンショット。

- 配送コース一覧：2026年10月25日11:13のユーザー提供スクリーンショット。
