本編20枚と主要パラメータの補足1枚、計21枚の16:9資料です。6枚目から実機デモへ切り替えられます。

3枚目で設計に込めた想い、10枚目で空走距離と制動距離、12〜14枚目で積荷・システム構成・保存データの境界を図解しています。15枚目は忘却の仕組みと再プレイのサイクル、16枚目はコース公開、17枚目はコースごとのランキングと記録の登録です。図・グラフ・文字はPowerPoint上で編集できます。フォントはHiragino Sansです。

PDFは日本語の表示崩れを避けるため、各ページを高解像度画像として収録しています。

人物コース・スマホ・登録・配送コース一覧はユーザー提供の実画面を使用。6枚目の走行画像は積荷2個保持・1個落下を示す編集画像、9枚目の色抽出図は実測ではなく抽出方法のイメージ図です。伝票の記録は撮影用のデモ値です。

GitHubへこのフォルダを送信すると、PDFへのリンクからプレビューできます。

ランキング図のチーム名・記録は説明用の例です。ゴール後のTOP3判定、チーム名登録、公開コース一覧での表示を実装に沿って説明しています。
