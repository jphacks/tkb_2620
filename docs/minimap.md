# 人型ミニマップ

ゲーム画面の右下に、実際に走るCourseDataの閉じた輪郭を固定方向で表示する。写真コースではその人型、サンプルでは楕円になる。

- `minimap.ts` はゲームの x/z 座標をSVGの x/y 座標へ変換する。負のzが上、正のxが右。縦横比を保ち、全体を余白付きで中央に収める。
- `CourseMinimap` はコースとチェッカーのSTART／GOAL旗、赤いピンの現在位置を描く。地図はトラックやカメラと一緒に回転しない。
- `createScene` が約0.1秒ごとに実際のトラック座標を通知する。停止中も現在位置を保ち、STARTへ戻すと点も戻る。写真コースを切り替えたときは新コースのSTARTから表示する。
- 地図はクリックを遮らず、カメラ操作や運転操作を妨げない。下部の説明文より上へ配置する。

`npm run test:minimap` で座標の方向、縮尺、余白、閉ループ、退化した範囲を確認する。画面では走行時の点の移動、カメラ切替時の向きの維持、STARTへ戻す動作を確認する。

## 初回だけの切り抜き写真

写真からコースを生成した直後は、全体図と初回走行のミニマップに人物だけを切り抜いた写真を表示する。マスク外を透明にした最大512pxのPNGをブラウザ内で作り、元写真→ゲーム座標の変換で道路と位置を合わせる。

写真とBlob URLは画面用のメモリにだけ持ち、CourseData・DB・通信・localStorageには追加しない。ページを離れるかリセット・再挑戦すると走行中の写真表示を外す。保存ルートなど写真の入力がない場合は最初から輪郭だけ。生成したBlob URLは表示終了時に解放する。プレビューの作成が失敗した場合も輪郭表示を続ける。

道路は全体図と同じ濃いグレー（#4a4f4a）、縁はコースのwallColorStopsに沿った人物カラー、現在位置は赤（#ff2d2d）と白い縁で表示する。

## マーカー

現在位置は赤い位置ピン、スタート／ゴールはチェッカー旗で表示する。荷物が荷台から離れた瞬間のワールド座標を保持し、黄色いバツを1個につき1つ表示する。バツは落下中の箱を追いかけず、着地後も残る。STARTへのリセットや新コースでは積荷が初期化され、バツも消える。地図の向きは引き続き固定。
