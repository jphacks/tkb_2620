# ゲームHUD（Issue #20）

TIME（経過時間）・CARGO（残り／総積荷）・SPEED（速度）を走行画面の左上にまとめる。ゲーム内の距離をmとして、速度m/sを3.6倍してkm/hに換算する。タイムと速度は桁幅をそろえて表示する。積荷が減ったときは数字と枠を黄色にする。

右下にはIssue #18の固定方向ミニマップをそのまま表示する。スマホ接続のQRとキーボード操作説明は開閉式で、必要なときだけ開く。カメラ切替とSTARTへのリセットは常時操作できる。

表示は既存のDrivingStatusを利用する。HUDの数値部分はクリックを遮らない。小さい画面では情報を縦に並べ、低い横長画面ではミニマップを小さくする。QRは閉じた状態から始まり、ルームの接続処理やゲーム物理には変更を加えない。
