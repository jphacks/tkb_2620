# 輪郭の平滑化（Issue #4）

写真画面の「輪郭の検証・平滑化の調整」で強さと繰り返し回数を変更し、元の輪郭と平滑化後をCanvasで比較する。写真がない場合はサンプル人型を使える。
初期値は3回・強度0.4。強度0または回数0なら元の点列を変更しない。UIは強度0〜1・回数0〜15、関数は最大30回まで。

`smoothClosedContour(points,width,height,options)` は画像の0〜1の点列を入力とし、`{points,iterationsApplied,warning}` を返す。画像の縦横寸法を使い、縦長写真でも距離を正しく扱う。

1. 仮の点を増やし、長い辺だけが平均から取り残されるのを防ぐ（間隔上限は画像長辺/180）。ゲーム用の等距離配置は後続Issueで行う。
2. 前後2点＋自身の5点の平均へ、強度に応じて少しずつ移動する。閉ループの先頭と末尾を接続し、全点を同時更新する。
3. 元の位置から長辺の1.8%までに移動を制限し、頭・腕・脚の大きな形を保つ。写真端の点は端に固定する。
4. 各更新後に輪郭の自己交差などを検証する。不正な更新は採用せず、最後の有効な点列と警告を返す。計算量の上限を超える場合も補正せず警告する。

強度は1回ごとの丸め具合、回数は丸める回数。強くしすぎると形が縮むため、比較しながら調整する。

「この写真を使う」で `CapturedPerson.outline`（元の点列）と `smoothedOutline`（平滑化後の点列）、`smoothingOptions` を保持する。設定変更時は確定を解除し、再確定が必要。表示の黄色い線はさらに二次曲線で描画するが、後続処理へ渡すデータは平滑化した `{x,y}[]`。
ここで扱う点は画像の正規化座標。メートル換算・最小半径の保証はまだ行わない。

確認：`npm run test:capture`、`npm run lint`、`npm run format:check`、`npm run build`。
