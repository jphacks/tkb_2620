# 壁との接触からの復帰

壁に当たっても自動リセットせず、ハンドルとアクセルで立て直せるようにする。タイム・積荷・周回判定はそのまま続く。STARTへ戻す操作は残す。

`updateGame` は接触時に前進の計算を打ち切らず、壁に沿う移動と向きの変更を試す。旋回後のトラックの幅・長さに必要な分だけ壁から離し、もとの位置と同じ側に保つ。移動量を小さく制限し、全壁との接触を再検証する。安全な姿勢を作れない場合はその刻みでは停止する。

接触中の前進は最大2m/sに抑える。アクセルを踏みブレーキを離している間は、低速でも2m/s相当の旋回速度を使い、止まったまま旋回できなくなることを防ぐ。通常走行時のハンドルの動きは変更しない。これはゲーム向けの復帰補助で、実車の厳密なタイヤ物理ではない。

`npm run test:wall`：正面衝突から左右へ復帰、側壁沿いの移動、高速でのすり抜け防止、ブレーキ中の停止、角での安全性を確認する。

## 逆走防止

周回判定と同じ近傍のコース区間から進行方向を取得し、トラックの向きが逆向きなら前進とクリープを止める。壁との接触補正による逆方向の移動も抑える。アクセルを踏みブレーキを離してハンドルを切ると、その場で低速旋回して向きを戻せる。向きが戻ると前進を再開する。タイム・積荷・周回状態をリセットしない。HUDには逆走防止中の操作案内を表示する。

`tests/wrong-way.test.ts` は逆向きのアクセル・惰性の停止、左右どちらの旋回でも復帰できること、正方向の走行維持、ブレーキ中の停止を確認する。
