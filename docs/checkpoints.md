# 道のりの看板と進み具合

お家までの道のりの 1/4・1/2・3/4 の地点に看板を立て、通過したことと、あとどれくらいかを、運転のじゃまにならない大きさで知らせる。

## 看板

`src/game/checkpointSigns.ts` が、道の外（お家と同じ側、壁の少し外）に看板を立てる。お家は一周の約9割の地点（`DELIVERY_RATIO`）にあるので、看板の位置は「お家までの道のり」を4つに分けた地点（一周の約22%・45%・67%）。

| 地点 | 看板の文字               |
| ---- | ------------------------ |
| 1/4  | 1/4 通過　安全運転で！   |
| 1/2  | 折り返し　荷物は無事？   |
| 3/4  | あと少し　お家はもうすぐ |

文字は近づいてくるトラックのほうの面にだけ貼り、少しだけ道のほうへ向ける。配送伝票と同じ、生成りの紙に濃い緑の文字と赤いはんこ色にする。坂のあるコースでは、看板は道路の高さに合わせ、柱は地面から立てる。

## 進み具合

`src/game/checkpoints.ts` の `routeProgress` が、周回判定（`lap.ts`）の `progress`（中心線に沿って前へ進んだ距離）を、お家までの道のりで割って0〜1にする。`createScene` は一番先まで進んだ割合を覚えておき、戻っても減らさない。お家に着いたら1、STARTに戻したら0にする。`DrivingStatus.route` で画面に渡す。

## 画面

左上のHUDの「配達中」の横に、看板で4つに分けた細いバー（「お家まで」）を出す。進んだ区間が黄色で埋まっていく。

看板の地点を通過すると、「配達中」のラベルが2.5秒だけ「1/4 通過！安全運転で！」などに変わる。ふだんと同じ場所・同じ大きさで、はんこの赤い枠にする。真ん中に大きく出すことはしない。動きを減らす設定では、出てくるときの動きをなくす。

`npm run test:checkpoints`：看板の位置、進んだ割合の範囲（逆走・行き過ぎ・不正な値）、通過した看板の数を確認する。
