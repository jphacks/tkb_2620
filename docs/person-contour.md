# 人物の外周抽出

写真画面の「輪郭の検証（マスク・外周・サンプル）」を開くと、Canvas 2Dで写真と外周・二値マスク・外周のみを比較できる。
写真未選択でも人型サンプルで確認可能。見切れ例はチェックボックスで切り替える。

## 関数

- `extractOuterContour(binaryMask, width, height)`：人物1・背景0のUint8Arrayから輪郭を取得する。画像左上が原点、右が+x、下が+y。戻り値はピクセル単位の `{x,y}[]`。
- `validateContour(points)`：点数・非有限値・重複点・短辺・辺の折り返し・自己交差・面積を検証し、`{valid,reason}` を返す。
- `extractPersonOutline`：既存コード互換の確率マスク入力。0.5で二値化し、表示用の0〜1の座標を返す。

4近傍でつながった最大領域を採用し、画像全体の0.5%未満（最低4画素）の領域は除外する。
各画素の境界を順にたどり、最大面積の外周だけを選ぶ。内部の穴や離れた領域は輪郭に含めない。
同一直線上の中間点は省く。輪郭は末尾に始点を重複させず、最後から最初への辺を含む閉ループとして扱う。
画像端の人物画素は画像の端に沿って閉じる。存在しない手足は補完しない。

無人・小さすぎる領域・不正な入力や輪郭ではエラー。写真画面は再判定・選び直しを案内し、写真確定を無効化する。

## 後続処理への受け渡し

`CapturedPerson.binaryMask` は推論結果を0.5で二値化したマスク（ノイズ除去前）。
`CapturedPerson.outline` は検証済みの正規化された外周。画像もマスクもメモリ内だけで保持する。
ピクセル座標は `{x: p.x * mask.width, y: p.y * mask.height}` で復元できる。
このIssueではメートルやゲーム座標への変換、平滑化、等間隔化、急カーブ補正は行わない。
自己交差の検査は辺同士を比較するためO(n²)。1万点を超える入力は拒否する。

## 確認

`npm run test:capture`：既存8件に二値入力APIと不正ループの検証を加えた10件。
`npm run lint` / `npm run format:check` / `npm run build`。
実写真のマスク自体の認識精度改善は別の調整となる。複数人が接した領域の分離は未対応。

## 表示用の丸め処理

`previewContour.ts` で縦横比を保った距離を使って仮の点を増やし、前後3点を含む7点の移動平均を強さ0.55で6回適用する。元の位置からの移動は画像長辺の1.8%以内に制限する。画像端の座標は固定し、交差する更新は採用しない。最後は中点を結ぶ二次曲線で描画する。黄色い線は6px。Canvasの検証表示も同じ曲線を使用する。
元の抽出点は変更しない。ゲーム用の平滑化・最小カーブ半径を保証する補正とは別の、見やすさのための表示処理である。

## 人物マスクの改善

Selfie Multiclass 256x256（float32 v1）に変更し、背景以外（髪・肌・顔・服・装飾品）をまとめた確率0.4以上を人物とする。最大領域の選択前に3×3の膨張→収縮で小さな切れ目を閉じる。写真端はクランプして見切れを保持する。大きく欠けた部分の復元や、指一本ごとの正確な分離は保証しない。モデルは初回に約16MB取得する。
