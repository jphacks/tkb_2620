# コース生成中・完成画面（Issue #10）

写真画面で「この写真を使う」を押すと、コース生成中 → 完成画面へ進む。完成画面で名前を付けて「このルートで遊ぶ」を押すと、ゲーム画面がそのコースに切り替わる。

## 画面の流れ

1. 写真（STEP 01）：写真を選び、輪郭・色・急カーブ補正を確認して「この写真を使う」。
2. コース生成中（STEP 02）：小さいトラックが円の上を反時計回りに走る演出を、最低1.6秒表示する（`prefers-reduced-motion` では止める）。その間に `generateCourse` で CourseData を作る。
3. 完成：人型コース全体を上から見た図（色つきの縁が壁、灰色が道路、赤い丸がSTART）、一周の長さ・道幅・全身/見切れを表示。急カーブが残る場合は注意を出す。
4. コース名を入力（20文字まで、空欄なら「なまえのないコース」）。
5. 「このルートで遊ぶ」でゲーム画面へ。ツールバーにコース名を表示する。「撮り直す」で写真を消して写真選択に戻る。
6. 生成に失敗したら理由と「撮り直す」を表示する。

## CourseData の作り方（`src/image-processing/generateCourse.ts`）

1. 座標：補正後コース（Issue #6、写真上のメートル・右が+x・下が+y）を、ゲーム空間（右が+X・画面の上が−Z）へ x→x・y→z で対応させ、中心を原点に移す。
2. 大きさ：いちばん長い辺が `courseSize`（初期値300）になるよう拡大・縮小する。写真の倍率（1px=0.05m）は仮の値で、そのままだと人物が20m程度になり、道幅6の道路同士が重なってトラックを置けないため。
3. 一本道に整える（`fitRoad`）：指や指の間のすき間など、道幅より細かい形があると、行きと帰りの道路やすき間の両側の道路が重なる。そこでコースを1マス=1の格子に塗り、
   - 膨張（`grow`=3）：細い部分を太らせ、細いすき間を埋める。出っ張った角（手先・足先）も半径3で丸くなる。
   - 閉じる（膨張→収縮、`concaveRadius`=2）：へこんだ角と残ったすき間を半径2以上に丸める。
   - 最も大きい領域の外周を取り直し、平滑化・道幅の半分の間隔で等間隔化し、半径6（トラックの最小回転半径）未満のカーブを補正する（最大移動2）。
   - 出っ張りを削る処理はしない。細い腕や手先が短くなり、人型に見えなくなるため。
   - コースが大きい（300）ので軽い整形で足り、離れた部分どうしの道路は道幅の1.5倍以上離れ、腕・脚・頭の形は残る（道路は元の輪郭より3外側を通る）。
4. 色・START・向き：整えた形に、元輪郭の代表色（Issue #8 の `colorExtraction`）を Issue #9 の `mapCourseColors` で対応づけ直す。元輪郭の START（Issue #7）に最も近い点が先頭になり、反時計回りにそろう。色がなければ灰色1色で、START・向きだけそろえる。
5. 壁の色は `wallColorStops`、テーマ色は壁で最も長く続く色。道幅は6.0（サンプルコースと同じ）。`captureMode` は全身判定なら `full_body`、それ以外は `clipped`。

## 粒度の調整（仮）

完成画面に、コースの粗さを試すためのスライダーを仮で置いている。値を変えて0.2秒止まると、その場でコースを作り直す。

| スライダー         | 中身                         | 初期値 | 範囲    |
| ------------------ | ---------------------------- | ------ | ------- |
| 細かい形を埋める量 | `fitRoad` の `grow`          | 3      | 0〜16   |
| へこみの丸め       | `fitRoad` の `concaveRadius` | 2      | 0〜30   |
| コースの大きさ     | `courseSize`                 | 300    | 80〜300 |

初期値は、スライダーで試して選んだ値（埋める量3・へこみの丸め2・大きさ300）。ヨガの写真では、道路の重なりはなく一周約1440m。
へこみの丸めが小さいため、脇・股などに半径6未満のカーブが残ることがある（ヨガの写真で12点、最小半径3.4）。

半径6未満のカーブが残った場合は、完成画面に「ゆっくり走ってください」と出す。

## 描画

写真のコースはサンプルコースより大きく、全体表示でカメラが遠くなると道路と地面が重なってちらつく（Zファイティング）。`createScene` の描画に `logarithmicDepthBuffer` を使い、遠くでも奥行きの精度を保つ。

コース名は CourseData に含めず、画面の状態として持つ。保存（Issue #25）で DB の列に対応させる。
大きさ・道幅の調整は Issue #27 で行う。

確認：`npm run test:course`（手の形の指・すき間、細い腕を含む） / `npm run test:colors` / `npm run test:curves` / `npm run test:capture` / `npm run lint` / `npm run format:check` / `npm run build`。
