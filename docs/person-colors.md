# 人物カラー抽出

写真画面の「人物の色を取り出す」で色取得位置を水色の点、元の輪郭を黄色の線で確認する。
代表色は輪郭の順に表示する。写真がなくてもサンプルの配色で確認できる。区間数と内側への距離倍率を調整可能。

## 処理

`extractRepresentativeColors(imageData,binaryMask,originalContour,config)` はThree.jsに依存しない関数。
入力画像のRGBA、マスク（人物1・背景0）、元の輪郭のピクセル座標を受け取る。画像とマスクの解像度差は幅・高さの比で吸収する。
写真画面は保存済みPNGの寸法を使って元の正規化輪郭をピクセルに戻す。平滑化後・等間隔化後の輪郭からは色を取らない。

1. 最後→最初も含む累積距離で元の輪郭を16区間に分ける。
2. 各区間の25%・50%・75%で接線を求め、左右の法線をマスクで検査して内向きを選ぶ。両側を区別できなければスキップする。
3. 内向きに3・6・10px移動し、画像内・マスク内・不透明な画素のみを採用する。実際の画素中心もマスクで再確認する。
4. RGB各チャンネルの中央値を代表色にする。サンプルがない区間は左右の有効区間から、距離に応じた補間で補完する（閉ループの境界も含む）。
5. 全失敗時は既定色RGB(160,160,160)と警告を返す。

出力 `colorSamples` は区間の中央の`t`、`startT`、`endT`、RGB、取得数、補完フラグを含む。`probes` は実際に採用した写真内の取得位置とRGB。`warnings` と適用した`config`も返す。
`t`は距離割合であり点番号ではない。区間番号は0始まり、画面表示は1始まり。

## 設定と保持

初期値は区間数16・各区間3地点・内側3/6/10px。距離は読み込み・回転・縮小後の写真に対するピクセル。
設定は関数引数で変更可能、UIの区間数は4〜32、距離は初期値の0.5〜3倍。
写真確定時に `CapturedPerson.colorExtraction` に保持する。処理中の未確定結果やサンプル配色を写真に混入させない。
設定を変えたら再確定が必要。写真はブラウザ内で処理し、送信しない。

マスクが背景を誤認識している場合にはその色が混じる可能性がある。髪・肌・服という意味ラベルごとの分類ではなく、輪郭上の位置に応じた代表色である。
補正後の道路へのマッピング・境界のグラデーション・壁メッシュはIssue #9以降で行う。

## 確認

`npm run test:capture`：背景の除外、マスク解像度差、逆向き輪郭、中央値、欠損補完、全失敗、輪郭端、点密度の違いを検証する。
`npm run lint` / `npm run format:check` / `npm run build`。
